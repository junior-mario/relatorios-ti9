# Relatórios TI9

Este repositório publica o relatório HTML de acompanhamento dos chamados TI9/Movidesk.

## Link esperado do GitHub Pages

Após habilitar o GitHub Pages nas configurações do repositório, o relatório ficará disponível em:

https://junior-mario.github.io/relatorios-ti9/

## Como habilitar

1. Acesse o repositório no GitHub.
2. Vá em **Settings**.
3. Acesse **Pages**.
4. Em **Build and deployment**, selecione:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/root**
5. Salve a configuração.

O arquivo principal publicado é `index.html`.
